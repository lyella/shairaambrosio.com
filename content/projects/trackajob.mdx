## Tech stack

React + TypeScript with plain CSS, deployed on Vercel. State is kept local-first so the tracker works offline and loads instantly.

## Problems

Job hunting means juggling dozens of applications across boards, emails, and spreadsheets — and losing track of follow-ups. Trackajob centralizes everything: companies, roles, status (applied / interviewing / offer / rejected), links, and notes.

## Lessons learned

Small tools beat big processes. A focused single-purpose app with a clean status pipeline ended up more useful than a generic spreadsheet, and keeping the data local-first made it fast and private by default.
